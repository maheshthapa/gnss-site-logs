# Nepal GNSS Site Logs Repository

This repository contains site logs for GNSS stations in Nepal, including both continuously operating reference stations (CORS) and stations that do not operate continuously but have a monument suitable for conversion to a continuously operating reference station.

## Repository Structure

```
.
├── design-documents/
├── karkhana/
├── site-logs/
├── old-site-logs/
├── gnss_sites.geojson
├── station_list.xlsx
├── station-map.jpg
└── README.md
```

## Directory & File Descriptions

- **`site-logs/`**
  Contains the most recent and actively updated GNSS site log files.

- **`old-site-logs/`**
  Archive of legacy/superseded site log files.
  *Note: Always refer to `site-logs/` for current, operational station records.*

- **`design-documents/`**
  Contains design drawings of GNSS station monuments.

- **`karkhana/`**
  Contains work-in-progress GNSS site logs.

- **`gnss_sites.geojson`**
  Geospatial data for GNSS station locations.

- **`station_list.xlsx`**
  Spreadsheet listing all monitored GNSS stations.

- **`station-map.jpg`**
  Map image showing the spatial distribution of GNSS stations.
